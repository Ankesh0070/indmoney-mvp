# INDmoney MVP

Academic fintech MVP demonstrating eight SIP-support workflows and a multilingual, no-investment-advice RAG app guide.

## Run

```bash
npm start
```

Open `http://localhost:4000`.

Production is built as a static site with `npm run build` and deployed from
the generated `dist/` directory.

## Test

```bash
npm test
```

This is a simulated academic prototype. It does not connect to a bank, execute payments, or provide investment advice.
